# Machine Learning – Study Material

## 1. Introduction to Machine Learning

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

### Types of Machine Learning

1. Supervised Learning
   - Uses labeled data.
   - Learns the relationship between input features and output labels.
   - Examples: Linear Regression, Logistic Regression, Decision Trees, Support Vector Machines.

2. Unsupervised Learning
   - Uses unlabeled data.
   - Discovers hidden patterns and structures.
   - Examples: K-Means Clustering, Hierarchical Clustering, PCA.

3. Reinforcement Learning
   - An agent learns by interacting with an environment.
   - Receives rewards or penalties based on its actions.
   - Examples: Game-playing agents and robotics.

## 2. Supervised Learning

Supervised learning uses a dataset containing input features and known output labels.

### Regression
Regression predicts continuous numerical values.

Examples:
- House price prediction.
- Salary prediction.
- Sales forecasting.

Common algorithms:
- Linear Regression
- Polynomial Regression
- Decision Tree Regression
- Random Forest Regression

### Classification
Classification predicts discrete categories or classes.

Examples:
- Spam or not spam.
- Diabetes prediction.
- Loan approval prediction.

Common algorithms:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Naive Bayes

## 3. Unsupervised Learning

Unsupervised learning works with data that does not contain predefined output labels.

### Clustering
Clustering groups similar data points together.

Examples:
- Customer segmentation.
- Grouping customers based on purchasing behavior.
- Document clustering.

Popular algorithms:
- K-Means
- Hierarchical Clustering
- DBSCAN

### Dimensionality Reduction
Dimensionality reduction reduces the number of features while retaining important information.

Popular technique:
- Principal Component Analysis (PCA).

## 4. Machine Learning Workflow

A typical machine learning project follows these steps:

1. Collect data.
2. Understand the dataset.
3. Perform data cleaning.
4. Handle missing values and duplicates.
5. Perform Exploratory Data Analysis (EDA).
6. Select relevant features.
7. Split data into training and testing sets.
8. Apply feature scaling when required.
9. Train a machine learning model.
10. Evaluate model performance.
11. Tune hyperparameters.
12. Deploy the model.

## 5. Training and Testing Data

Training data is used to teach the model patterns from the dataset.

Testing data is used to evaluate how well the trained model performs on unseen data.

A common split is:
- 80% training data.
- 20% testing data.

The model should generalize well to new data rather than simply memorizing training examples.

## 6. Overfitting and Underfitting

### Overfitting
Overfitting occurs when a model learns the training data too closely, including noise and irrelevant patterns.

Characteristics:
- High training accuracy.
- Low testing accuracy.
- Poor generalization.

Solutions:
- Regularization.
- Cross-validation.
- Feature selection.
- More training data.
- Pruning decision trees.

### Underfitting
Underfitting occurs when a model is too simple to capture important patterns in the data.

Characteristics:
- Poor training performance.
- Poor testing performance.

Solutions:
- Use a more complex model.
- Add relevant features.
- Reduce excessive regularization.
- Improve feature engineering.

## 7. Important Evaluation Metrics

### Confusion Matrix

A confusion matrix summarizes classification predictions.

- True Positive (TP): Correctly predicted positive cases.
- True Negative (TN): Correctly predicted negative cases.
- False Positive (FP): Negative cases incorrectly predicted as positive.
- False Negative (FN): Positive cases incorrectly predicted as negative.

### Accuracy

Accuracy measures the proportion of correct predictions.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

### Precision

Precision measures how many predicted positive cases are actually positive.

Precision = TP / (TP + FP)

### Recall

Recall measures how many actual positive cases are correctly identified.

Recall = TP / (TP + FN)

### F1-Score

F1-score is the harmonic mean of precision and recall.

F1-Score = 2 × (Precision × Recall) / (Precision + Recall)

## 8. Feature Engineering and Preprocessing

Feature engineering involves creating or transforming features to improve model performance.

Important preprocessing techniques:

- Missing value handling.
- Duplicate removal.
- Label Encoding.
- One-Hot Encoding.
- Standardization.
- Normalization.
- Outlier handling.

### Standardization

Standardization transforms features to have approximately zero mean and unit standard deviation.

### Normalization

Normalization scales values into a specified range, commonly between 0 and 1.

## 9. Important Machine Learning Algorithms

### Linear Regression
Predicts continuous values by modeling a linear relationship between independent and dependent variables.

### Logistic Regression
A classification algorithm that estimates the probability of a class using the logistic function.

### Decision Tree
Uses a tree-like structure of decisions to make predictions.

### Random Forest
Combines multiple decision trees to improve predictive performance and reduce variance.

### K-Nearest Neighbors
Predicts the class or value based on nearby data points.

### Support Vector Machine
Finds a decision boundary that separates classes while maximizing the margin between them.

### K-Means Clustering
Partitions data into K clusters based on similarity and distance from cluster centroids.

### Naive Bayes
A probabilistic classification algorithm based on Bayes' theorem and a conditional independence assumption.

## 10. Cross-Validation and Regularization

### Cross-Validation
Cross-validation evaluates a model using multiple training and validation splits.

K-Fold Cross-Validation divides the dataset into K subsets and uses each subset for validation in turn.

### Regularization
Regularization helps prevent overfitting by penalizing model complexity.

- L1 Regularization (Lasso): Can shrink some coefficients to zero.
- L2 Regularization (Ridge): Penalizes large coefficients.

## 11. Bias-Variance Tradeoff

Bias is the error caused by overly simple assumptions in a model.

Variance is the error caused by excessive sensitivity to training data.

A good machine learning model balances bias and variance to achieve good generalization.

- Recommendation systems.
- Customer segmentation.
- Image recognition.
- Speech recognition.
- Predictive maintenance.
- Financial forecasting.
- Natural Language Processing.

## Conclusion

Machine Learning enables systems to learn from data and make intelligent predictions. Understanding algorithms, data preprocessing, model evaluation, overfitting, underfitting, and model optimization is essential for developing reliable machine learning solutions.
